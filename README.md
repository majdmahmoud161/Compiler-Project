## نص المشروع

القوالب Jinja2 إلنشاء صفحات ديناميكية. ويتم استخدام HTML و CSS لبناء الواجهات وتصميم الشكل
العام للتطبيق . يوفّر Flask بيئة خفيفة وسهلة لبناء تطبيقات ويب قابلة للتطوير والعمل على مختلف
األنظمة.
